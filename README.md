# Shri Ram Janmabhoomi Mandir

A single-page, static HTML and CSS website introducing the Shri Ram
Janmabhoomi Mandir in Ayodhya.

The page focuses on semantic HTML headings, links, lists, an image, and an
embedded map. The illustration is stored locally; the map is provided by
Google Maps and needs an internet connection.

## Run locally

Open `index.html` in a web browser. There is no build step or external
dependency.

This is an independent educational project, not an official temple website.
Check current visitor information with official communications before
travelling.
